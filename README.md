# ✈️ Uçuş Programı - Windows Forms

## 📌 Proje Açıklaması
Bu proje C# ve Windows Forms kullanılarak geliştirilmiş basit bir uçuş bileti alma uygulamasıdır.  
Kullanıcı uçuş seçimi yapabilir, koltuk belirleyebilir ve toplam ücret hesaplanır.

## 🚀 Özellikler
- Nereden / Nereye uçuş seçimi
- Uçuş bilgilerinin dosyadan okunması
- Koltuk seçimi ekranı
- Ekstra hizmet seçimi
- Dinamik fiyat hesaplama
- Bilet özetinin gösterilmesi

## 🛠 Kullanılan Teknolojiler
- C#
- .NET 8
- Windows Forms

## 📂 Proje Yapısı
- `Form1` → Uçuş seçim ekranı
- `Form2` → Koltuk ve hizmet seçim ekranı
- `sehirler1.txt` → Uçuş ve fiyat bilgileri

## ▶️ Çalıştırma
Projeyi Visual Studio ile açıp `Build` aldıktan sonra çalıştırabilirsiniz.
